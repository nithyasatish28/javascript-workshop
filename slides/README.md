## The interactive deck

`02-why-frontend/index.html` runs in any browser. Open it with Live Server, or online once GitHub Pages is on:
`https://nithyasatish28.github.io/javascript-workshop/slides/02-why-frontend/`

Keys: → and ← to move (a clicker works too), N for notes, O for all slides, T for a timer, F for fullscreen. Anything typed into it (sticky notes, votes) is saved only in your own browser.

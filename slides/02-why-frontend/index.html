    Three roles build every app

    DESIGNArchitect
    FRONTENDBuilder
    BACKENDPlumbing

    Design: the architect. Decides how the app should work and look before anything is built: the flow of screens, the layout, the colours, the words on each button. Their output is sketches and mockups, not code.

    Frontend: the builder of the rooms. Turns the design into something real people can see and use: screens, buttons, forms, what happens when you tap. Runs on the user’s own phone or laptop. Everything we’ve talked about so far (the Pay button, the annoying apps) lives here.

    Backend: the plumbing and wiring. The hidden work: servers, databases, payments, checking rules. You never see it, but the house is useless without it.

    Full-stack: someone who does both frontend and backend. In small teams one person may do all three roles.

    Ask: “Think of the Pay test we just ran. Which role decided what the error message said? Which role built it? Which role actually moved the money?”

    Small choices, big problems

    Press → for each problem. Ask the class what is wrong before clicking “Fix it”.

    1) Light grey text: hard to read in sunlight or with weak eyes. 2) Tiny buttons close together: fingers miss. 3) A box that doesn’t grow: a long dish name hides the price. None of these are “making it pretty”; all are frontend decisions.

    Five habits for this course

    1Build first.
    2Predict, then run.
    3Explain it.
    4Ask a person before AI. Yourself, a classmate, then me.
    5Learn every line, every word.

    Press → for each habit and say why it exists.

    1) Build first: hands on keyboards within minutes; you remember what you build. 2) Predict, then run: guess what the code will do first; a wrong guess means you just learned something. 3) Explain it: if you can’t explain a line, it doesn’t go in. 4) Ask yourself first, then a classmate, then me, before asking AI: the struggle is where the learning happens. 5) Learn every line and every word of the code you write: no mystery lines.

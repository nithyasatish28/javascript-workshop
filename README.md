# JavaScript Workshop: from Python to React

A hands-on frontend workshop for students who already know some Python, databases, product requirements (PRDs) and data structures. Over three sessions you go from your first line of JavaScript to a React app that fetches live data.

Every session follows the same rhythm: **predict, then run → build in small steps → test it → explain a line.**

## What you will build

| Day | App | You learn |
| --- | --- | --- |
| [Day 1](day-1-javascript/) | **Canteen Order**: tap dishes, see the order and the total | JavaScript basics, the DOM, events |
| [Day 2](day-2-react/) | **Hostel Split**: an expense tracker, built twice | Plain JavaScript, then React: components and state |
| [Day 3](day-3-real-data/) | **SkyCheck**: “Do I need an umbrella?” | Fetching real data from an API, loading and error states |

Each app folder has a `starter/` (where you begin) and a `solution/` (one finished version, to compare with after you have tried).

## Before the first session

Follow [setup.md](setup.md): VS Code, the Live Server extension, a browser with DevTools, and (for Days 2 and 3) Node.js.

## How to use this repo

1. Click **Fork** (top right) to get your own copy, then clone your fork.
2. Open the repo folder in VS Code.
3. For each session, work inside that day's `starter/` folder.
4. Stuck? Read the day's README first, then compare with `solution/`. Try for ten minutes before you look.

Five habits for this workshop: build first, predict then run, explain it, ask a person (yourself, a classmate, then the instructor) before asking AI, and learn every line and every word of your code.

# JavaScript Workshop: from Python to the browser

A hands-on frontend workshop for students who already know some Python, databases, product requirements (PRDs) and data structures. In one day you go from your first line of JavaScript to a working app in the browser.

Every session follows the same rhythm: **predict, then run → build in small steps → test it → explain a line.**

## What you will build

| Day | App | You learn |
| --- | --- | --- |
| [Day 1](day-1-javascript/) | **Canteen Order**: tap dishes, see the order and the total | JavaScript basics, the DOM, events |

The app folder has a `starter/` (where you begin) and a `solution/` (one finished version, to compare with after you have tried).
Note: solutions will be added at the end of the day, you are supposed to try it out and run the code again to understand it better. keep this as your daily practice.

## How to use this repo

1. Click **Fork** (top right) to get your own copy, then clone your fork.
2. Open the repo folder in VS Code.
3. Work inside the `starter/` folders.
4. Stuck? Read the [Day 1 README](day-1-javascript/) first, then compare with `solution/`. Try for ten minutes before you look.

Five habits for this workshop: build first, predict then run, explain it, ask a person (yourself, a classmate, then the instructor) before asking AI, and learn every line and every word of your code.

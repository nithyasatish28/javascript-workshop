# Products: React starter

This project is ready for Step 3 of the lesson. Steps 1 and 2 (create the app and clean the starter code) are already done.

## Run it

```bash
npm install
npm run dev
```

Open http://localhost:5173. You should see the word "Products".

## What's here

- `src/App.jsx`: shows only the "Products" heading. You will add to this.
- `src/index.css`: the styles for the product list, already filled in.
- `src/components/`: empty. Your `ProductItem.jsx` and `ProductList.jsx` go here.
- `starter.html`: the plain HTML version of the page, for reference. Open it in a browser to see what you are building.

## Your task

Show 10 product names from this API, using a `ProductList` and a `ProductItem` component:

https://dummyjson.com/products?limit=10&select=title
